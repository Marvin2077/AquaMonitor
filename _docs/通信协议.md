# AquaMonitor 固件串口通信协议

本文档描述 AquaMonitor 固件当前的串口命令和设备响应格式。默认波特率为 `115200`。

## 基本格式

主机发送命令以换行符结束：

```text
$CMD,<MODULE>,<ACTION>[,<PARAMS>]*
```

设备响应以一行文本返回：

```text
$<MODULE>,<ACTION>,<FIELDS...>*
$ERR,<MODULE>,<ERROR_CODE>*
```

说明：

- `*` 为协议帧结束标记。
- 每条命令建议以 `\n` 结尾，`\r\n` 也可以。
- 模块名和动作名在固件解析时会转为大写。
- 串口命令行最长约 127 字符，超过会返回 `$ERR,SERIAL,LINE_TOO_LONG*`。
- 默认固件只输出协议报文；调试日志需要编译时打开 `FW_DEBUG_LOG=1`。

## 正式命令

### 系统

| 命令 | 说明 | 成功响应 |
|---|---|---|
| `$CMD,SYS,FACTORY_RESET*` | 清除已保存的校准参数并恢复默认值 | `$SYS,FACTORY_RESET,OK*` |

启动完成后设备输出：

```text
$SYS,READY*
```

设备 ID 未设置时：

```text
$ERR,DEVICE_ID,NOT_SET*
```

此时可发送：

```text
id 1
```

成功后返回：

```text
$SYS,DEVICE_ID,SAVED,1*
```

### 温度

| 命令 | 说明 | 成功响应 |
|---|---|---|
| `$CMD,TEMP,READ*` | 读取温度 | `$TEMP,MEAS,<temp_c>*` |
| `$CMD,TEMP,GET_CALIB*` | 查询温度校准系数 | `$TEMP,CALIB,<a>,<b>,<c>,<valid>*` |
| `$CMD,TEMP,SET_CALIB,<a>,<b>,<c>*` | 设置温度校准系数 | `$TEMP,CALIB,SET,OK*` |

温度三点校准目前正式 `$CMD` 协议未覆盖，仍通过兼容文本命令执行，见“兼容文本命令”。

温度相关响应：

```text
$TEMP,MEAS,<temp_c>*
$TEMP,RES,<ohm>*
$TEMP,CAL_PT,<index>,<standard_temp_c>,OK*
$TEMP,CALIB,OK,<a>,<b>,<c>*
$TEMP,CALIB,RESET,OK*
```

### 电导率

| 命令 | 说明 | 参数范围 | 成功响应 |
|---|---|---|---|
| `$CMD,COND,INIT*` | 初始化电导率模式 | 无 | `$COND,INIT,OK*` |
| `$CMD,COND,READ*` | 单次电导率测量 | 需先 `COND INIT` | `$COND,MEAS,...*` |
| `$CMD,COND,SWEEP*` | 执行扫频测量 | 需先 `COND INIT` | `$COND,SWEEP_START,<total>*`，随后多条 `$COND,SWEEP,...*`，最后 `$COND,SWEEP_END*` |
| `$CMD,COND,SET_FREQ,<hz>*` | 设置单频测量频率 | `2000` 到 `200000` Hz | `$COND,FREQ_SET,<hz>*` |
| `$CMD,COND,SET_VPP,<mv>*` | 设置激励电压峰峰值 | `50` 到 `800` mVpp | `$COND,VPP_SET,<mv>*` |

单次测量响应：

```text
$COND,MEAS,<freq_hz>,<mag_ohm>,<phase_deg>,<real_ohm>,<imag_ohm>,<conductance_us>*
```

扫频测量响应：

```text
$COND,SWEEP_START,<total_points>*
$COND,SWEEP,<index>,<total>,<freq_hz>,<mag_ohm>,<phase_deg>,<real_ohm>,<imag_ohm>,<conductance_us>*
$COND,SWEEP_END*
```

### pH

| 命令 | 说明 | 参数范围 | 成功响应 |
|---|---|---|---|
| `$CMD,PH,INIT*` | 初始化 pH 模式 | 无 | `$PH,INIT,OK*` |
| `$CMD,PH,READ*` | pH/ISFET 原始测量 | 需先 `PH INIT` | 多条 `$PH,MEAS,...*`，最后 `$PH,MEAS_DONE,<count>*` |
| `$CMD,PH,CAL_OFFSET*` | 校准零点 offset | 需先 `PH INIT` | `$PH,CAL_OFFSET,START*`，完成后 `$PH,CAL_OFFSET,OK,<offset_code>*` |
| `$CMD,PH,CAL_GAIN,<res_ohm>*` | 用标准电阻校准 Rtia | `res_ohm > 0` | `$PH,CAL_GAIN,START,<res_ohm>*`，完成后 `$PH,CAL_GAIN,OK,...*` |
| `$CMD,PH,SET_ISFET,<channel>*` | 设置 ISFET 通道 | `1` 到 `8` | `$PH,ISFET,OK,<channel>*` |

pH 测量响应：

```text
$PH,MEAS,<idx>,<total>,<raw_code>,<voltage_diff_v>,<current_ua>,<rtia_ohm>,<offset_code>*
$PH,MEAS_DONE,<count>*
```

pH 校准响应：

```text
$PH,CAL_OFFSET,START*
$PH,CAL_OFFSET,OK,<offset_code>*
$PH,CAL_GAIN,START,<res_ohm>*
$PH,CAL_GAIN,OK,<rtia_ohm>,<res_ohm>,<raw_code>,<voltage_diff_v>*
```

## 错误响应

通用错误：

| 响应 | 含义 |
|---|---|
| `$ERR,SYS,UNKNOWN_CMD*` | 未知命令或格式非法 |
| `$ERR,SYS,BUSY*` | 当前状态忙，不能接收新命令 |
| `$ERR,SERIAL,LINE_TOO_LONG*` | 串口命令行过长 |
| `$ERR,DEVICE_ID,NOT_SET*` | 设备 ID 未设置 |
| `$ERR,DEVICE_ID,INVALID*` | 设备 ID 设置命令非法 |

启动/硬件错误：

| 响应 | 含义 |
|---|---|
| `$ERR,AD5941,PLATFORM_CONFIG_FAILED*` | AD5941 平台初始化失败 |
| `$ERR,ADS124S08,CONFIG_FAILED*` | ADS124S08 配置失败 |
| `$ERR,BT,INIT_FAILED*` | 蓝牙初始化失败 |

温度错误：

| 响应 | 含义 |
|---|---|
| `$ERR,TEMP,MEASURE_FAILED*` | 温度测量失败 |
| `$ERR,TEMP,CAL_PT1_FAILED*` | 温度第 1 个校准点采集失败 |
| `$ERR,TEMP,CAL_PT2_FAILED*` | 温度第 2 个校准点采集失败 |
| `$ERR,TEMP,CAL_PT3_FAILED*` | 温度第 3 个校准点采集失败 |
| `$ERR,TEMP,CALIB_CALC_FAILED*` | 温度三点校准计算失败 |
| `$ERR,TEMP,RESISTANCE_READ_FAILED*` | 温度原始电阻读取失败 |

电导率错误：

| 响应 | 含义 |
|---|---|
| `$ERR,COND,NOT_IN_MODE*` | 未处于电导率模式 |
| `$ERR,COND,NOT_INITIALIZED*` | 电导率服务未初始化 |
| `$ERR,COND,INIT_FAILED*` | 电导率初始化失败 |
| `$ERR,COND,SWEEP_INIT_FAILED*` | 电导率扫频初始化失败 |
| `$ERR,COND,ALREADY_SWEEPING*` | 当前已在扫频 |
| `$ERR,COND,FREQ_SET_FAILED*` | 设置频率失败 |
| `$ERR,COND,VPP_SET_FAILED*` | 设置 Vpp 失败 |
| `$ERR,COND,MEASURE_TIMEOUT*` | 电导率单次测量超时 |
| `$ERR,COND,SWEEP_TIMEOUT*` | 电导率扫频超时 |

pH 错误：

| 响应 | 含义 |
|---|---|
| `$ERR,PH,NOT_IN_MODE*` | 未处于 pH 模式 |
| `$ERR,PH,NOT_INITIALIZED*` | pH 服务未初始化 |
| `$ERR,PH,INIT_FAILED*` | pH 初始化失败 |
| `$ERR,PH,CAL_OFFSET_INIT_FAILED*` | pH offset 校准初始化失败 |
| `$ERR,PH,CAL_GAIN_INIT_FAILED*` | pH gain 校准初始化失败 |
| `$ERR,PH,MEASURE_TIMEOUT*` | pH 测量超时 |
| `$ERR,PH,CAL_OFFSET_TIMEOUT*` | pH offset 校准超时 |
| `$ERR,PH,CAL_GAIN_TIMEOUT*` | pH gain 校准超时 |
| `$ERR,PH,SIGNAL_LOW,<abs_volt>*` | pH gain 校准信号过低 |

## 兼容文本命令

以下命令仍被固件支持，主要用于人工调试。上位机建议优先使用 `$CMD,...*` 正式协议。

### 温度

| 文本命令 | 等效操作 |
|---|---|
| `temp read` | 读取温度 |
| `temp cal 25` | 采集 25°C 校准点 |
| `temp cal 35` | 采集 35°C 校准点 |
| `temp cal 50` | 采集 50°C 校准点 |
| `temp save` | 计算并保存温度校准 |
| `temp reset` | 清除温度校准 |
| `temp resistance` | 读取温度原始电阻 |
| `GET_TEMP_CALIB` | 查询温度校准系数 |
| `SET_TEMP_CALIB <a> <b> <c>` | 设置温度校准系数 |

### 电导率

| 文本命令 | 等效操作 |
|---|---|
| `cond init` | 初始化电导率模式 |
| `cond read` | 电导率单次测量 |
| `cond sweep` | 电导率扫频 |
| `cond freq <hz>` | 设置频率 |
| `cond vpp <mv>` | 设置 Vpp |

### pH

| 文本命令 | 等效操作 |
|---|---|
| `ph init` | 初始化 pH 模式 |
| `ph read` | pH 测量 |
| `ph cal offset` | pH offset 校准 |
| `ph cal gain <res_ohm>` | pH gain 校准 |
| `ph isfet <channel>` | 设置 ISFET 通道 |

### 系统

| 文本命令 | 等效操作 |
|---|---|
| `factory reset` | 恢复默认校准参数 |
| `id <number>` | 首次设置设备 ID |

## 典型流程

### 电导率单次测量

```text
主机 -> $CMD,COND,INIT*
设备 <- $COND,INIT,OK*
主机 -> $CMD,COND,READ*
设备 <- $COND,MEAS,1000.00,1234.56,-1.23,1234.00,-12.00,810.0000*
```

### pH 测量

```text
主机 -> $CMD,PH,INIT*
设备 <- $PH,INIT,OK*
主机 -> $CMD,PH,READ*
设备 <- $PH,MEAS,1,1,32780,0.000671,0.003948,170000.00,32768*
设备 <- $PH,MEAS_DONE,1*
```

### 温度校准

```text
主机 -> temp cal 25
设备 <- $TEMP,CAL_PT,1,25.0,OK*
主机 -> temp cal 35
设备 <- $TEMP,CAL_PT,2,35.0,OK*
主机 -> temp cal 50
设备 <- $TEMP,CAL_PT,3,50.0,OK*
主机 -> temp save
设备 <- $TEMP,CALIB,OK,<a>,<b>,<c>*
```
